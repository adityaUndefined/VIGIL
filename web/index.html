How VIGIL shifts the balance

Scammers rely on urgency, panic, and technical obfuscation to bypass human judgment. VIGIL intercepts these attacks by running a deterministic, local-first policy engine that strips away the deception. It translates hidden code and psychological manipulation into clear, plain-language alerts — giving people the critical seconds they need to pause, think, and stay safe.

Four steps, zero cloud

From suspicion to verdict — in milliseconds

01

Content in

A message, a URL, or raw HTML enters the analyzer — from the extension, the API, or your agent harness.

02

Signal extraction

The analyzer parses structure and language, extracting security signals from what is written and what is hidden.

03

Deterministic scoring

A local rules engine scores every signal. No cloud round-trip, no prompt leakage — the verdict path works fully offline.

04

Evidence + verdict

ALLOW, WARN or DENY — always with the exact evidence that produced it, so humans and agents can verify before trusting.

One security layer, many surfaces

Everything gets scanned

Message analysis

Paste any SMS, chat or email and get an instant, evidence-backed risk read — including impersonation and urgency tricks that target seniors.

URL analysis, without visiting

Links are analyzed purely as text. VIGIL inspects suspicious structures — look-alike domains, punycode, redirect tricks — without ever navigating.

HTML source analysis

Paste page source. VIGIL reads the DOM humans never see and flags hidden layers crafted to deceive people or machines.

Agent action review

Before an AI agent sends data or clicks a link, VIGIL reviews the proposed action and returns an evidence-backed gate: ALLOW, WARN or DENY.

Local-first, offline verdicts

The rules engine runs entirely on-device — no internet, no data leaving the machine. An optional local Ollama model adds plain-language explanations.
