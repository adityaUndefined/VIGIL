# Security Policy

## Supported Versions

The latest version on the `main` branch is currently supported.

## Reporting a Vulnerability

If you discover a security vulnerability in VIGIL, please report it privately rather than opening a public GitHub issue.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any proof-of-concept or relevant logs, if available
- The affected version or commit

## Responsible Disclosure

Please do not publicly disclose a vulnerability before there has been reasonable opportunity to investigate and address it.

## Scope

VIGIL is a hackathon MVP. It is intended for security research, experimentation, and demonstration purposes.

The project should not be treated as a complete production security system.

## Privacy

Please do not include passwords, API keys, access tokens, personal information, or other sensitive data in vulnerability reports.

## Contact

For private vulnerability reports, use the repository owner's GitHub contact or security reporting features available on the repository.
